# EdgeNotes releases

Signed and notarized builds of **EdgeNotes**, a macOS sidebar notes app that opens from the screen edge.

- Download the latest `EdgeNotes-x.y.z.dmg` from [Releases](../../releases/latest), open it and drag EdgeNotes to Applications.
- Requires macOS 14 or later (Apple silicon).
- EdgeNotes checks this repository for updates (`appcast.xml` on the latest release). Updates are verified with an EdDSA signature.

This repository only hosts the builds. The source is not published.
